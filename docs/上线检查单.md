# MES 生产上线检查单

- 版本基线：Flyway **V109**（…V108 汇算增强、V109 广告费结转与跨年台账）
- 适用范围：报价 → 技术评审 → 转销售订单 → BOM 任务 → MRP 运算 → 生产执行 → 发货 → 应收开票/收款核销 → 总账与期间关账
- 使用方式：逐项确认并签字，**A 类全部通过才允许上线**

---

## A. 上线阻断项（必须全部通过）

### A1. 版本与产物
- [ ] 所有改动已提交并打 tag（建议 `mes-v1.0.0`），可随时切回上一版
- [ ] `mes-backend/target/mes-backend-1.0.0.jar` 构建时间为本次发布
- [ ] `mes-frontend/dist` 已同步到 `mes-backend/src/main/resources/static`，`index.html` 引用的 JS 哈希与本次构建一致
- [ ] 前端构建通过（`npm run build`），后端全量测试通过（434 用例，0 失败）
- [ ] 发版后确认 `index.html` 响应头为 `no-store`；个别客户端如仍显示旧界面，强制刷新一次（Ctrl+F5）

### A2. 生产配置（`SPRING_PROFILES_ACTIVE=prod`）
启动时以下变量缺一不可，缺任意一个服务会直接起不来：

- [ ] `DB_URL`、`DB_USER`、`DB_PASSWORD`
- [ ] `JWT_SECRET`（≥32 字符，`openssl rand -base64 48` 生成）
- [ ] `MES_CORS_ORIGINS`（生产域名，不要用 `*`）
- [ ] `MES_INIT_PASSWORD`（初始化口令，首次登录强制改密）
- [ ] `DB_POOL_SIZE` / `DB_POOL_MIN_IDLE`（默认 20 / 5，按压测结果调）
- [ ] JVM 时区 `Asia/Shanghai`
- [ ] 附件存储目录已挂载且纳入备份（上传图纸/报价附件，单文件 20MB）
- [ ] 日志目录已挂载、可写、纳入轮转
- [ ] 反向代理已配 HTTPS，`/actuator` 仅内网可访问

### A3. 数据库与账号
- [ ] 迁移前已做一次全量备份（见 A4）
- [ ] **应用账号与迁移账号分离**：应用账号只能 DML，不能建表/改表
- [ ] 应用账号对 `flyway_schema_history` 至少有 SELECT 权限（否则 Flyway 启动即失败）
- [ ] 启动后校验 Flyway 版本：

```sql
select version, description, success
from flyway_schema_history
order by installed_rank desc limit 3;
-- 期望：102 / 101 / 100，success = t
```

- [ ] 校验订单币种字段与数据：

```sql
select column_name from information_schema.columns
where table_name = 'sales_order' and column_name = 'currency';

select count(*) from sales_order where currency not in ('CNY','USD','EUR');  -- 期望 0

select count(*) from sales_quote
where net_amount + tax_amount <> total_amount;                                -- 期望 0
```

### A4. 备份与回滚
- [ ] 手动执行一次备份并确认产物：`powershell -ExecutionPolicy Bypass -File scripts\backup.ps1`
- [ ] 备份包含数据库 dump + 附件目录，脚本自检（`pg_restore --list`）通过
- [ ] **恢复演练已做过**：`pg_restore` 到临时库，抽查销售订单、报价单、BOM 任务各 1 条
- [ ] 备份已挂计划任务（建议每日 02:00，保留 14~30 天）
- [ ] 回滚剧本已确认：停服 → 恢复最近备份 → 换回上一版 jar → 启动 → 冒烟
- [ ] 明确本次发布的责任人与回滚决策人

### A5. 关键流程 UAT（生产同构环境，用真实角色账号）
报价员（`QUOTER`）
- [ ] 新建报价：币种、税率、含税/未税、付款条件、明细、附件上传
- [ ] 提交评审；被驳回后修改并重新提交
- [ ] 只能看到自己的报价单（数据范围生效）
- [ ] 打印报价单，金额三件套（未税 + 税额 = 价税合计）正确

技术评审（`TECH`）
- [ ] 评审通过 / 驳回（驳回必须填意见）
- [ ] 会签：多个评审人全部通过才 APPROVED
- [ ] 转办、加签、撤签；管理员代审有审计记录

销售（`SALES`）
- [ ] 转销售订单：订单带出来源报价、订单币种、含税单价
- [ ] 校验 **订单金额 = 报价价税合计**（外币单同样校验）
- [ ] 重复转单被拦截

计划 / 技术（`PLANNER` / `TECH`）
- [ ] 计划员派 BOM 任务，技术员能收到待办
- [ ] BOM 未完成时 MRP 阻断；半成品缺 BOM 同样阻断并提示缺哪一层
- [ ] BOM 完成且生效后才能跑 MRP

仓库 / 生产
- [ ] 领料、报工、入库不受影响

管理员
- [ ] 角色权限分配正确；任务与通知能收到
- [ ] 工作台本月销售额为人民币口径（仅 CNY 订单）

### A6. 定时任务
- [ ] 每天 09:15 `QUOTE_BOM_REMINDER` 已触发（看任务/通知/日志）
- [ ] 到期前提醒处理人；逾期升级提醒报价人与派单计划员
- [ ] 手动在「定时任务」页触发一次，确认执行成功

### A7. 财务上线（应收 + 总账）
- [ ] 给财务人员分配 `FINANCE` 角色（或按需给现有角色补 `finance:*` 权限），首次登录后确认菜单与按钮可见
- [ ] 总账「科目」页默认科目齐全（银行存款、应收、预收、库存、应付、固定资产、累计折旧、销项/进项/未交增值税/附加税/所得税、收入、成本、折旧费用、税金及附加、资产处置损益、所得税费用）
- [ ] **期初余额已录入**：用「手工凭证」把各科目期初余额做成一张借贷平衡的凭证（开账日所在期间）
- [ ] 外币业务先维护「汇率」：1 外币 = ? 人民币；没有汇率时外币发票会被拒绝，这是预期行为
- [ ] 发货单开票：金额拆分正确（未税 + 税额 = 价税合计），凭证在「总账-记账凭证」可见且借贷平衡
- [ ] 收款登记并核销：发票状态从已开票 → 部分收款 → 已收清；取消收款后状态回退且凭证红冲
- [ ] 未核销的收款进入「预收账款」，后续在收款单上「核销预收」转到新发票；核销过的收款单不能直接取消
- [ ] 销售退货用红字发票冲减，应收余额与账龄同步减少
- [ ] 「试算平衡」借贷相等；有差异先查凭证再关账
- [ ] **期间关账**：每月结账后关闭期间；关账后新增发票/收款会被拒绝
- [ ] 采购发票与付款在「总账-同步应付凭证」补记，重复点击不会重复记账
- [ ] 月结「销售/应收」已改为按销售发票（本位币）统计，与应收台账一致
- [ ] 财务口径确认：单账套、人民币本位币；外币按记账汇率折算，不做汇兑损益重估

### A8. 固定资产与税务申报
固定资产
- [ ] 资产卡片原值、残值率、使用月数正确；折旧从购置次月起计提
- [ ] 期初导入资产关闭「生成购置凭证」，避免重复计入银行付款
- [ ] 按月「计提折旧」：金额 =（原值 ×（1-残值率））÷ 使用月数，重复执行不重复计提
- [ ] 折旧凭证借贷平衡，折旧明细能按资产/期间查到
- [ ] 资产处置：原值、累计折旧、处置款、处置损益一次结平，凭证借贷平衡

税务申报
- [ ] 销项税额、进项税额与总账「销项税额 / 进项税额」科目本期发生额一致
- [ ] 应交增值税 = max(销项 − 进项, 0)；进项大于销项时形成留抵，不结转
- [ ] 附加税税率确认（默认城建 7%、教育 3%、地方教育 2%）
- [ ] **先申报再关账**：申报结转凭证记在所属期最后一天，关账后无法申报
- [ ] 申报 → 缴款流程走通，申报/附加税/缴款凭证借贷平衡
- [ ] 已申报期间不能重新生成申报表

企业所得税季度预缴
- [ ] 每季度生成预缴表：累计利润 × 税率 = 累计应纳税额，本期应预缴 = 累计应纳税额 − 本年以前季度已预缴
- [ ] Q1 无利润时为 0；后续季度有利润时按累计口径补差，不重复预缴
- [ ] 预缴申报生成计提凭证（借所得税费用 / 贷应交所得税），缴款生成付款凭证，均借贷平衡
- [ ] 已申报季度不能重算；预缴凭证记在季度末，先预缴再关账
- [ ] 年度汇算生成时「已预缴税额」自动带出本年季度预缴合计（可手工调整）

企业所得税汇算清缴
- [ ] 会计利润与总账收入类、费用类科目全年发生额一致（不含所得税费用本身）
- [ ] 纳税调整（调增/调减）逐项录入，应纳税所得额 = 会计利润 + 调增 − 调减 − 弥补亏损
- [ ] 可弥补亏损余额与近 5 年已申报亏损一致，弥补额不超过余额
- [ ] 税率、减免税额、已预缴税额确认；应补（退）= 应纳税额 − 减免 − 已预缴
- [ ] 申报生成计提凭证（借所得税费用 / 贷应交所得税），凭证借贷平衡
- [ ] 补税或退税登记生成对应凭证；申报后不能重算
- [ ] **先汇算再关账**：计提凭证记在税款所属年度 12-31
- [ ] 纳税调整「按规则自动带出」：业务招待费、广告费、罚款、研发加计扣除金额与台账一致
- [ ] 小型微利：应纳税所得额 ≤300 万、人数 ≤300、资产 ≤5000 万时按实际 5% 计税，减免额自动计算
- [ ] 研发辅助账：按项目归集人员人工/直接投入/折旧/摊销，汇算加计扣除直接取台账金额
- [ ] 分支机构：维护分摊比例（合计 ≤100%），申报后自动生成分摊表，总机构拿剩余与尾差
- [ ] 「打印申报表」能输出汇算主表、调整明细与分摊表
- [ ] 广告费超限部分结转以后年度：当年超限调增、次年先用当年额度再扣结转额，结转余额逐年递减到 0
- [ ] 「跨年台账」能按年度/规则查询调整明细、计算基数、限额与结转余额，且只在申报后落账

## C. 口径与边界（本期明确，不按缺陷处理）

| 项目 | 规则 |
| --- | --- |
| 订单币种 | 支持 CNY / USD / EUR；报价转单时快照，手工建单可选 |
| 币种换算 | 订单层不做换算；财务层按「汇率」表折算本位币记账，外币无汇率不能开票 |
| 经营统计 | 人民币本位币口径，只汇总 CNY 订单（销售金额）；应收/总账按本位币 |
| 应收口径 | 以**销售发票**为准（发货单开票），收款按发票核销；月结应收=发票-红字-收款 |
| 会计账套 | 单账套、人民币本位币；不做多法人账套、不做汇兑损益重估 |
| 财务范围 | 应收、收款核销、预收、总账凭证、期间关账、试算平衡、固定资产、增值税及附加申报、所得税季度预缴与年度汇算（含研发辅助账、分支机构分摊）；采购应付凭证由「同步应付凭证」补记 |
| 企业所得税 | 季度按累计利润预缴；年度会计利润取总账（不含所得税费用）；调整规则自动取科目发生额/研发台账；广告费超限结转以后年度；小型微利实际 5%；分支机构按比例分摊 |
| 暂不包括 | 印花税/房产税等小税种、现金流量表、合并报表、多账套、工资 |
| 外币对账 | 外币发票保留原币与汇率，本位币入账；原币对账报表列为下期 |
| 套料 | 已确认舍弃，MES 只承载工单与附件，不做套料算法与数据导入 |
| 报价打印 | 浏览器打印，不做服务端 PDF 归档 |
| 报价税率 | 默认 13%，0~100% 可调；金额按 2 位小数四舍五入 |
