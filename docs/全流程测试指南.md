## 1. 主数据搭建顺序（必须按这个顺序）

推荐顺序：

```
组织 / 工作中心 → 工序 → 仓库（可选库位） → 产品 → BOM → 工艺路线 → 客户 / 供应商
```

原因：

- 工序要绑定工作中心，工作中心要挂在组织下
- 产品工艺路线要引用工序
- BOM 要引用产品和物料
- 销售订单要引用客户和产品
- 采购订单要引用供应商和产品

### 1.1 建议先建一套最小数据

| 类型 | 编码 | 名称 | 关键参数 |
|------|------|------|----------|
| 组织 | PLANT01 | 智造工厂 | 已有，根节点 |
| 工作中心 | WC-CUT | 下料中心 | 日产能 480 分钟 |
| 工作中心 | WC-ASSY | 装配中心 | 日产能 480 分钟 |
| 工序 | CUT | 下料 | 绑定 WC-CUT，单件工时 1.5 分，工价 0.6 |
| 工序 | MACH | 机加工 | 绑定 WC-CUT，单件工时 3 分，工价 1.1 |
| 工序 | ASSY | 装配 | 绑定 WC-ASSY，单件工时 2 分，工价 1.2 |
| 工序 | QC | 终检 | 绑定 WC-ASSY，检验模式选“独立检验工序” |
| 仓库 | WH-RAW | 原料仓 | 类型：原料仓 |
| 仓库 | WH-FIN | 成品仓 | 类型：成品仓 |
| 产品 | RM-001 | 铝合金板 | 原料，单位 kg，安全库存 100 |
| 产品 | FG-001 | 铝合金支架 | 成品，单位 件，销售价 120，成本 60 |
| BOM | — | FG-001 用料 | RM-001 用量 0.5 |

| 客户 | C-001 | 测试客户 | 等级 A |
| 供应商 | S-001 | 测试供应商 | 类型 MATERIAL |

> 编码都可以留空：新建工作中心 / 工序 / 仓库 / 产品 / 客户 / 供应商时会按「系统管理 → 编码规则」自动生成（默认 WC001、OP001、WH001、PD0001、CUS001、SUP001），也可以手工改成上面表格里的可读编码。编码规则里可调整前缀、流水位数。

### 1.2 组织与工作中心

入口：**系统管理 → 组织架构**

1. 在组织树中确认根节点 `PLANT01`
2. 新建车间/班组（可选）
3. 切到页签 **工作中心**，新建 `WC-CUT`、`WC-ASSY`
4. 填写日产能分钟数（默认 480）
5. 在工作中心行可以维护设备台账（后续 OEE 用）

验收：工作中心列表出现 2 条，组织树能正常展开。

### 1.3 用户与角色

入口：**系统管理 → 用户管理 / 角色权限**

1. 新建用户：`planner`、`warehouse`、`qc`、`operator`
2. 分配角色：PLANNER / WAREHOUSE / QC / OPERATOR
3. 把用户挂到对应组织
4. 用新账号登录一次，确认菜单按角色收敛

验收：计划员看不到成本与系统管理；仓库看不到排产。

### 1.4 仓库与库位

入口：**基础数据 → 仓库管理 / 仓储管理 → 库位管理**

1. 新建 `WH-RAW`（原料仓）、`WH-FIN`（成品仓）
2. 类型必须选对：生产领料固定从原料仓出，完工入库与发货走成品仓
3. 可选：为仓库建库位 `A-01`、`A-02`

验收：仓库类型正确；库位挂在对应仓库下。

### 1.5 工序

入口：**基础数据 → 工序管理**

1. 新建 `CUT / MACH / ASSY / QC`
2. 绑定工作中心
3. 填默认工时、计件工价
4. `QC` 的检验方式选“独立检验工序”，其余选“不检验”
5. 保持启用

验收：工序列表 4 条，工作中心列显示正确。

### 1.6 物料主数据、BOM、工艺路线

入口：**基础数据 → 物料主数据**、**基础数据 → BOM 管理**

1. 在「物料主数据」新建原料 `RM-001`（类别 RAW，默认来源外购，单位 kg，提前期 10 天，安全库存 100）
2. 新建成品 `FG-001`（类别 FINISHED，默认来源自制，单位 件，提前期 3 天，销售价 120，成本 60）
3. 选中 `FG-001` → 打开 **工艺路线**，依次添加 `CUT / MACH / ASSY / QC`
4. 到「BOM 管理」新建 BOM：父件选 `FG-001`，版本 `V1.0`，基础数量 1，生效日期选今天
5. 打开该 BOM 的「明细」，添加 `RM-001`，用量 0.5，保存后回到列表点「提交审批」
6. 到「审批中心」用管理员账号通过这条 BOM 审批，版本会自动变为「生效」
7. 保存后确认物料主数据里的“工艺路线数量”大于 0

验收：物料列表 2 条；`FG-001` 有 1 套生效 BOM（1 行明细）、4 道工序。

> BOM 按版本维护：新建一律是草稿，提交审批通过后才生效；同一物料只有一套生效版本。工单和 MRP 按「生效 + 当天在生效区间内」的版本取料。
>
> 生效、审批中的版本明细只读。需要改料或改量时，在 BOM 管理里点「复制新版本」，维护后重新提交审批；驳回或撤回会回到草稿。
>
> 如果产品没有工艺路线，下达工单后工序会是空的；可以在工单详情「工序」页签手工补（之前已加这个入口）。

### 1.7 客户与供应商

入口：**基础数据 → 客户管理**、**采购与应付 → 供应商档案**

1. 新建客户 `C-001`
2. 新建供应商 `S-001`（类型 MATERIAL）
3. 可选：维护供应商账期、交期天数、采购员

验收：销售订单能选到客户，采购订单能选到供应商。

## 2. 销售到交付

入口：**销售与交付 → 销售订单**

1. 新建销售订单，选择客户 `C-001`
2. 添加明细：产品 `FG-001`，数量 10，交期设为 7 天后
3. 保存后点 **审核**（或确认）
4. 点 **运行 MRP**

预期：

- 先扣成品现有库存：净生产量 = 订单数量 − 成品库存
- 自制件按净生产量逐层展开，生成成品/半成品生产工单（草稿），带工序与 BOM 快照
- 外购件跨层汇总后扣库存、在途与已申请，每种物料生成一张采购申请（草稿，需审批后转采购单）
- 销售订单状态变为“生产中”；如果库存足够，直接变为“待发货”，不生成任何单据
- 成品工单的计划数量 = 净生产量，不再是订单原始数量

> 运行结果会弹窗展示：成品净需求、每层自制/外购净需求、建议开工日/建议下单日、生成的工单与采购申请。
>
> 同一张订单只能运行一次 MRP；重复运行会被已有工单拦住，避免重复下单。

## 3. 生产执行（核心链路）

入口：**生产执行 → 生产工单**

### 3.1 下达

1. 打开工单详情
2. 确认追溯方式（按数量 / 单件）
3. 点 **下达**

预期：状态从草稿/已排产变为“已下达”，可以领料和报工。

### 3.2 领料

1. 工单详情 → **领料**（或「按工序领料」）
2. 选择原料仓 `WH-RAW`，填写领料人
3. 提交

预期：

- 生成领料单
- 工单物料行的“已领数量”增加
- 库存 `RM-001` 减少，库存流水增加一条出库记录

### 3.3 排产与插单模拟

入口：**计划与排产 → 排产计划 / 排产甘特**

1. 在排产计划里给工单指定日期
2. 打开排产甘特，确认工单条出现在对应日期
3. 按住任意有色格子，拖到另一个工作中心/日期
4. 松手后应弹出「拖动模拟：移单影响」

预期弹窗显示：是否装得下、新预计完成日、总工时、受影响工单数、产能冲突。

### 3.4 报工

入口：工单详情 → **报工**，或 **生产执行 → 车间扫码**

1. 选择工序 `CUT`
2. 填写报工数量 10、合格数量 10
3. 提交
4. 依次报完 MACH、ASSY、QC

预期：

- 每道工序完成数量增加
- 工单进度条推进
- 如果开了单件追溯，可在「单件追踪」看到 10 个件码

### 3.5 检验

入口：**质量与设备 → 质量检验**

1. 新建检验单：类型选“过程/完工”，关联工单与产品
2. 填写检验数量 10、不良 0，结论合格
3. 提交

预期：检验单出现在列表，合格率统计增加。

### 3.6 完工与入库

1. 所有工序报完后，工单状态可进入已完工
2. 进入 **仓储管理 → 入库管理**
3. 点 **新建无单入库**
4. 选择成品仓 `WH-FIN`，来源填“完工入库”，添加 `FG-001` 数量 10

预期：成品库存增加，库存流水增加入库记录。

### 3.7 发货

入口：**销售与交付 → 发货管理**

1. 新建发货单，选择客户与销售订单
2. 添加 `FG-001` 数量 10
3. 提交并点 **发货**
4. 可选：签收

预期：销售订单状态变为已发货/已完成；成品库存减少。

## 4. 采购到应付

入口：**采购与应付**

1. **采购申请**：新建申请，添加 `RM-001`，数量 200，提交
2. 如果开了审批，去 **概览 → 审批中心** 审批通过
3. **采购订单**：从申请转采购单，或直接新建；选择供应商 `S-001`
4. 确认采购单
5. 点 **收货**，选择原料仓，填写收货数量
6. 生成入库单，去 **入库管理** 完成入库
7. 如果来料检验：在 **质量检验** 新建来料检验
8. **发票与应付**：登记发票、做三单匹配、付款
9. 可选：**采购退货** 走退货流程

预期：库存增加、应付金额增加、付款后应付减少。

---

## 5. 库存

入口：**仓储管理**

1. **期初库存**：入库管理 → 新建无单入库，来源“期初盘点建账”
2. **出库**：出库管理 → 新建出库单（非生产领料）
3. **调拨**：库存调拨 → 新建调拨单 → 完成（源仓减、目标仓加）
4. **盘点**：库存盘点 → 新建盘点 → 录入实盘 → 完成（按差异调整）
5. **批次追溯**：批次追溯 → 输入批次号/单号，查看出入库链路

验收：

- 结存 = 期初 + 入库 − 出库 ± 调拨/盘点
- 每个动作都有库存流水

## 6. 质量

入口：**质量与设备**

1. 质量检验：分别测来料、过程、完工三类检验
2. 不良处置：对不合格品登记不良，选择处置方式（返修/报废/让步）
3. 过程能力 SPC：录入/查看检验数据，检查 CPK 图
4. 返修：不良处置生成返修工单，回到生产执行报工

验收：检验单、不良记录、返修工单能互相关联。

## 10. 经营大屏与分组工作台

### 10.2 分组工作台

入口：点击左侧任意分组标题（销售与交付、计划与排产、生产执行、采购与应付、仓储管理、质量与设备、报表分析、基础数据、系统管理）

- 修改预警天数（如 3 天）

验收：预警条目能点开对应单据（单号可核对）；改月份/预警天数后指标变化。

## 附录 C：常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 新建销售订单选不到产品 | 主数据为空 | 先建产品和客户 |
| 下达工单后没有工序 | 产品没有工艺路线 | 物料主数据 → 工艺路线，或工单详情手工补工序 |
| 排产甘特没有数据 | 工单没排产日期或没有工序 | 先排产；确认工序已生成 |
| 领料提示没有可领物料 | 产品没有 BOM，或已领足 | 检查 BOM 与领料数量 |
| 入库/出库选不到仓库 | 仓库未建或类型不对 | 基础数据 → 仓库管理，类型选原料仓/成品仓 |
| 经营大屏数据为 0 | 没有业务数据或时间区间不对 | 先走一单完整流程，再切本月 |
| 分组工作台提示缺工艺路线 | 产品未配路线 | 物料主数据 → 工艺路线 |
| 中文乱码（psql） | PowerShell 编码 | 设置 `PGCLIENTENCODING=UTF8`，或改用页面操作 |
